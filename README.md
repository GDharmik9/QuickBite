# QuickBite 🍔

QuickBite is a responsive web application built with React that allows users to discover local restaurants, explore food menus, and place meal orders seamlessly.

## ✨ Features

- **User Authentication:** Secure sign-up and login functionality.
- **Restaurant Discovery:** Fetch and browse all available restaurants via backend APIs.
- **Restaurant Details & Menus:** Detailed view pages displaying full menu offerings, pricing, and item descriptions.
- **Responsive Interface:** Clean, component-driven UI optimized for desktop and mobile screens.

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
- **Tooling:** Create React App, npm
- **API Communication:** RESTful API integration for user auth and restaurant catalog

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js and npm installed.

### Installation & Setup
1. Clone the repository:
   ```bash
   git clone [https://github.com/GDharmik9/QuickBite.git](https://github.com/GDharmik9/QuickBite.git)
   cd QuickBite
   ```
2. Install dependencies:
  ```Bash
    npm install
  ```
3. Run the development server:
  ```Bash
    npm start
  ```

Open http://localhost:3000 to view the app in your browser.
